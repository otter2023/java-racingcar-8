## 🎯 미션 개요
무작위로 생성된 0~9 사이의 숫자가 4 이상일 때 전진하는 자동차 경주 게임을 구현한다.

<br>

## 📝 기능 요구 사항

### 1. 자동차 이름 입력
- 사용자는 쉼표(`,`)로 구분된 자동차 이름을 입력한다.
- 각 자동차의 이름은 **5자 이하**이어야 한다.

### 2. 이동 횟수 입력
- 사용자는 몇 번의 이동을 시도할지 정수로 입력한다.

### 3. 자동차 전진 조건
- 0에서 9 사이의 랜덤 값을 구해 **4 이상일 경우 전진**한다.
- 랜덤 값은 `camp.nextstep.edu.missionutils.Randoms.pickNumberInRange(0, 9)`를 활용한다.

### 4. 실행 결과 출력
- 각 라운드별로 모든 자동차의 전진 상태를 출력한다.
- 전진한 횟수만큼 `-` 문자로 표시한다.

### 5. 우승자 판별
- 모든 라운드가 종료된 후 가장 많이 전진한 자동차가 우승자이다.
- 우승자가 여러 명이면 쉼표(`,`)로 구분하여 함께 출력한다.

### 6. 예외 처리
- 사용자가 잘못된 입력을 할 경우 `IllegalArgumentException`을 발생시키고 애플리케이션은 종료되어야 한다.
- 예외 발생 시 `System.exit()`는 사용하지 않는다.

<br>

## 📥 입출력 요구 사항

### 입력
- 경주할 자동차 이름 (쉼표로 구분)
```
pobi,woni,jun
```
- 시도할 횟수
```
5
```
### 출력
- 차수별 실행 결과
```
pobi : --
woni : ----
jun : ---
```
- 최종 우승자 안내 문구
```
최종 우승자 : pobi, jun
```

**입출력 예시**
```
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
pobi,woni,jun
시도할 횟수는 몇 회인가요?
2
```
실행 결과
```
pobi : -
woni :
jun : -

pobi : --
woni : -
jun : --

최종 우승자 : pobi, jun
```

## 📋 구현할 기능 목록

### ✅ 필수 기능
- [ ] 사용자 입력 처리  
  - 자동차 이름(문자열) 입력  
  - 시도 횟수(정수) 입력
- [ ] 입력 문자열 파싱  
  - 쉼표(`,`) 기준으로 자동차 이름 분리  
- [ ] 랜덤 전진 로직
    - `Randoms.pickNumberInRange(0, 9)` 값이 4 이상이면 전진
- [ ] 라운드 진행  
  - 시도 횟수만큼 반복  
  - 매 라운드별 자동차 상태 출력
- [ ] 우승자 계산 및 출력

### 🚨 예외 처리
- [ ] 자동차 이름이 5자 초과인 경우
- [ ] 시도 횟수가 양의 정수가 아닌 경우

### 🧩 추가 고려 사항
- [ ] 공백 단독은 잘못된 이름으로 처리
- [ ] 이름에 특수문자 포함 시 잘못된 이름으로 처리
